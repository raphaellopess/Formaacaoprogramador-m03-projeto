\ MEU SISTEMA BANCÁRIO - FORMAÇÃO PROGRAMADOR



O objetivo do porjeto é treinar os conhecimentos adquiridos ao longo da Formação Programador durante o môdulo 3 , ultilizando estruturas de repetição e estutruras de dados para criar um script em Python que possibilite a simulação de operações bancárias do dia a dia. 



\### FUNCIONALIDADE:



Para isso tomamos com bases os seguintes requisitos/operações:



0\. Um menu com seleção de operação.

1\. Criação de contas.

2\. Remoção de contas.

3\. Listagem de todas as contas criadas.

4\. Adicionar saldo.

5\. Remover saldo.

6\. Transferir valor entre contas.

7\. Consultar saldo de conta especifica. 



\### ESTRUTURA DE DADOS:



&#x20;As contas devem ser armanezadas e cada conta deve ser um dicionário (chave/valor) contendo as seguintes chaves : 



\- numero\_conta

\- saldo\_conta
